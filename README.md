# aayogima · Nothing × Material 3 Expressive — ч/б bio одним экраном

Страница **@aayogima** (маршмело⁴²): дизайн **Nothing** — **строго чёрно-белый**
(dot-matrix, hairlines, glyph-полоска) с элементами **Material 3 Expressive**
(морфинг форм, тон, ripple, снэкбар). Единственный цвет — **фирменный красный
Nothing** (точка-REC и номера блоков).

**Не скролл-сайт** — весь контент на одном экране, **без 3D**.

## Темы · инверсия ч/б
- кнопка **инверсии** в шапке (иконка «половина круга»): тёмная ⇄ светлая
- тёмная: чёрный фон, белые элементы; светлая: белый фон, чёрные — оба строго ч/б
- выбор запоминается в `localStorage`, по умолчанию — системная тема
- прямые ссылки: `#dark` / `#light` (например, для шаринга)
- QR, красная точка и аватар-кот одинаково читаются в обеих темах

## Что на экране
| Колонка | Блоки |
|---|---|
| Левая | `01 профиль` (имя, цитата про анонимность, теги) · `02 цифры` (42 / 06 / 00 в dot-шрифте) · `03 саундтрек` (плеер fakemink) |
| Центр | аватар-кот с **морфингом Material-форм** (cookie → clover → burst → arch…), glyph-кольцо вокруг, выбор формы, `@aayogima` в dot-matrix, кнопки |
| Правая | `04 контакт` (**QR с красной скан-подсветкой**, бесплатное ЛС без звёзд) · `05 терминал` (ASCII-арты) |
| Ниже | `06 посты` — лента из `post.py` (появляется, когда есть посты) |

- верх: красная точка-REC (единственный цвет), часы МСК, online, кнопка темы
- низ: бегущая dot-matrix строка

## Терминал `05` · ASCII
Живой терминал (инвертируется вместе с темой: чёрный ⇄ белый) с автосценами:
- `$ neofetch` — ASCII-кот + профиль: тема, шелл, **живой трек**, звёзды
- `$ shapes --ascii` — **актуальная форма аватара в ASCII** (рендер из того же
  полигона: кликнул форму в центре — увидишь её в терминале)
- `$ fortune -a` — случайные цитаты (анонимность, 42, ч/б)
- `$ uname -a`, `$ dm --cost` — GlyphOS и «стоимость лс: 0 звёзд, free»
- печатает посимвольно, курсор мигает красным, строки скроллятся

## Детали
- **Nothing**: шрифт Doto (dot-matrix как Ndot82), тонкие hairline-линии,
  моноширинные технические аннотации `01…05` (красные номера), ч/б палитра
- **M3E**: 8 материальных форм плавно морфятся (48-точечные полигоны), тон-карточки,
  ripple на кнопках, снэкбар при копировании, пружинные ховеры
- **Музыка fakemink** — 6 треков, случайный при заходе; glyph-кольцо оживает
  во время воспроизведения, трек виден в `neofetch` терминала
- **QR**: `https://t.me/aayogima?free=zUEtBAujyA53A8gD` — бесплатное ЛС без звёзд;
  скан-линия подсвечена **красным** (фирменный акцент Nothing)
- Морфинг форм — 2D clip-path, никаких 3D-трансформаций
- Один экран на десктопе — пока нет постов, скролла нет вообще;
  лента постов ниже делает страницу скроллящейся (это ожидаемо)

## Запуск
```bash

python3 -m http.server 8079
# → http://localhost:8079        (тёмная/светлая — кнопкой в шапке)
# → http://localhost:8079/#light (сразу светлая)
```

## Посты · post.py
Пишешь что хочешь, картинки любые (jpg/png/webp/gif, длинная сторона сжимается до 1600px):
```bash
python3 post.py "текст поста"                # текст
python3 post.py "текст" -i photo.jpg         # текст + картинка
python3 post.py -i meme.png                  # только картинка
python3 post.py                              # интерактивно (многострочный текст)
python3 post.py --file draft.txt             # текст из файла
python3 post.py --pin "важное"               # сразу закрепить
python3 post.py --list                       # список постов
python3 post.py --edit p2 "новый текст"      # сменить текст
python3 post.py --edit p2 -i new.jpg         # сменить картинку
python3 post.py --pin p2                     # закрепить/открепить
python3 post.py --delete p2                  # удалить
```
- посты: `assets/posts/posts.json`, картинки: `assets/posts/`
- на сайте лента появляется под первым экраном (без постов секция скрыта — снова ровно один экран)
- в тексте работают переводы строк и ссылки (подчёркнуты красным)
- картинка открывается на весь экран кликом (лайтбокс), Esc — закрыть
- после публикации просто обнови страницу в браузере
